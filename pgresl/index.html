Abstract

Dexterous grasping with anthropomorphic multi-fingered hands remains challenging due to the high-dimensional action space, complex contact dynamics, and limited generalization of existing policies under diverse approach directions and functional grasping constraints. Although recent methods have achieved strong performance in standard top-down grasping scenarios, they often struggle to handle universal-direction grasping and diverse interaction poses, where the robot must approach objects from arbitrary directions and maintain robust hand-object interaction.

In this paper, we propose PG-RPO, a Prior-Guided Residual Policy Optimization framework for robust and generalizable dexterous grasping. The key idea is to use task-relevant grasping priors to reduce the exploration difficulty of reinforcement learning in the high-dimensional dexterous hand action space. Specifically, we first extract semantic-aware reference action sequences from input text prompts and object point clouds, which provide coarse but meaningful grasping trajectories. We then train a diffusion-transformer-based behavior cloning policy to predict base grasping actions conditioned on these reference actions and the hand-object state representation. During reinforcement learning, the behavior cloning policy is frozen and used as a base policy, while a residual policy learns fine-grained corrective action offsets to improve grasp robustness and physical feasibility.

Extensive experiments in simulation demonstrate that PG-RPO achieves competitive performance in standard top-down grasping and significantly improves success rates in the more challenging universal-direction setting. PG-RPO also generalizes well to unseen objects, cross-dataset objects, and diverse functional grasp poses. Furthermore, real-world experiments with a dexterous robotic hand validate the physical feasibility and transferability of the proposed framework.


Framework Overview

PG-RPO consists of three main components. First, a prior grasp extraction module generates semantic-aware reference actions from the input text prompt and object point cloud. Second, a diffusion-transformer-based behavior cloning policy predicts base action chunks from the current state and the reference action sequence. Finally, a residual reinforcement learning policy learns corrective action offsets on top of the base actions, enabling robust dexterous grasping under diverse object shapes and approach directions.


Universal-Direction Dexterous Grasping

Unlike conventional top-down grasping methods, PG-RPO supports universal-direction dexterous grasping, where the hand approaches the object from diverse directions on the upper hemisphere. The reference-guided base policy provides a meaningful initial action prior, while residual reinforcement learning further adapts the grasping behavior to contact dynamics and object geometry.


Quantitative Results

PG-RPO is benchmarked against representative dexterous grasping baselines in both top-down and universal-direction grasping settings. In the challenging universal-direction setting, PG-RPO achieves strong generalization on unseen objects and cross-dataset objects, demonstrating the effectiveness of using semantic priors, behavior cloning, and residual reinforcement learning together.


Ablation Study

We conduct ablation studies to analyze the contribution of each component in PG-RPO, including reference actions, the behavior cloning base policy, and the residual reinforcement learning policy. The results show that reference actions provide important semantic guidance, the base policy constrains exploration with meaningful grasping priors, and residual reinforcement learning is critical for fine-grained adjustment during physical interaction.


Real-World Validation

To evaluate the sim-to-real transferability of PG-RPO, we conduct real-world experiments using a dexterous robotic hand and a robotic arm. The generated trajectories are retargeted to the physical hand and executed on real objects. The results demonstrate that PG-RPO can generate stable and physically feasible grasping trajectories across diverse functional poses.
